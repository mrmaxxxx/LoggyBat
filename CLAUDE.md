# LoggyBat — контекст для Claude

Виджет WidBar для Windows 11 для пользователей беспроводной техники Logitech:
показывает заряд устройств, которые видит Logitech G HUB, прямо на панели задач.
Данные — из G HUB (WebSocket `ws://localhost:9010`). LGSTrayBattery не нужен.
Поддержку техники вне G HUB не заявляем.

Тестовые устройства Макса: мышь G502 X PLUS и гарнитура PRO X Wireless —
это не единственные поддерживаемые модели, в коде к ним ничего не привязано.

Устройство проекта, сборка и установка: [docs/HANDOFF.md](docs/HANDOFF.md).

## Пользователь

- Макс, общаться по-русски, пошаговые инструкции без лишней теории.
- Visual Studio и .NET SDK на компьютере нет: собирать только через GitHub Actions.

## Правила работы

- Push, merge, изменение `main`, переименование репозитория на GitHub,
  удаление установленных пакетов — только с явного разрешения Макса.
  Разрешение действует на конкретное действие, не навсегда.
- Репозиторий: https://github.com/mrmaxxxx/LoggyBat. Основная ветка — `main`
  (актуальный код, по push в неё запускается сборка). Ветка `loggybat` сохранена
  как история перехода. В какой ветке вести новую работу — согласовывать с Максом.
- Логические коммиты; не смешивать переименование и изменение логики в одном коммите.
  Коммиты только с документацией — с `[skip ci]`, чтобы не расходовать номер сборки.
- Успешная сборка ≠ проверка на железе. В отчётах для каждого пункта:
  проверено / не проверено / есть проблема.
- Дизайн (иконки, проценты, ⚡, —, размеры, шрифты, цвета, компоновка flyout)
  не менять без отдельной задачи. Для мыши + гарнитуры вид должен остаться
  `🖱 92%   🎧 69%` — это закреплено в tests/GHubProtocolCheck.
- Не выдумывать постоянный ID устройства: его в G HUB надёжно нет (см. ниже).
- Закрытый ключ подписи никогда не попадает в репозиторий, логи и артефакты.
- Код LGSTrayBattery под GPLv3: не копировать, писать своё по протоколу.
- Версии пакетов (WidBar.SDK, WindowsAppSDK, .NET) не обновлять без причины.

## Что известно о G HUB (проверено 2026-10-30 на компьютере Макса)

- `GET /devices/list`, `GET /battery/<id>/state` работают; ответ приходит с тем же `msgId`.
  Заряд получен для мыши (92%) и гарнитуры (69%).
- У устройства есть `capabilities.hasBatteryStatus`, `deviceType` (MOUSE, HEADSET,
  CAMERA…), `displayName`, `deviceModel`.
- `devNNNNNNNN` — временные номера, меняются после перезапуска G HUB.
- Постоянного ID экземпляра для всех устройств нет: `deviceSignature` у мыши
  содержит серийный номер, у гарнитуры — нет, `deviceUnitId` у гарнитуры пустой.
- Выключенная гарнитура остаётся в списке ACTIVE, а заряд: `INVALID_ARG`,
  «Battery data not available».
- Выключенная мышь LIGHTSPEED (G502 X PLUS): `state=NOT_CONNECTED`, `activeInterfaces=[]`,
  `GET /battery/<id>/state` → `NO_SUCH_PATH` (замер 2026-10-30, выключение ~10 с).
- Времени измерения в ответе нет: показываем только время получения ответа.
- Строка `deviceType` для клавиатуры (`KEYBOARD`) не проверена на реальном устройстве.
- События приходят после `SUBSCRIBE` на `/devices/state/changed` и `/battery/state/changed`
  (`verb=BROADCAST`, свой msgId, ответа на сам SUBSCRIBE нет). Виджет использует их
  только как сигнал «перечитать»; опрос раз в 10 с — подстраховка.
- Расхождение 90% (GET) и 89% (окно G HUB) не объяснено. Округление не менять без данных.
