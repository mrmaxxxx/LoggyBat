# Уведомления о сторонних компонентах

## WidBar widget template

LoggyBat создан на основе шаблона
[andelby/widbar-widget-template](https://github.com/andelby/widbar-widget-template).
Части проекта, взятые из этого шаблона (структура проектов, файлы запуска виджета,
проект MSIX-упаковки, справка в папке `wiki/`), распространяются на условиях лицензии
шаблона, приведённой ниже без изменений (файл `LICENSE` шаблона, коммит `2f56f17`).
